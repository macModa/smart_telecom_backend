# Smart Telecom Backend

A backend web application developed with **Python and Django** for a
telecommunication-oriented project.

## 🎯 Project Overview

This project was developed to gain practical experience in backend
development using Django.

The application is structured as a Django project with a dedicated
`offers` application and database persistence.

## 🛠️ Tech Stack

- Python
- Django
- SQLite
- Git
- GitHub

## ✨ Key Features

- Django-based backend
- Telecom offers management
- Database persistence
- Modular Django application structure
- Backend business logic

🚀 Getting Started
Prerequisites

Make sure you have:

Python 3.x
pip
Git
Clone the repository
git clone https://github.com/macModa/smart_telecom_backend.git
cd smart_telecom_backend
Create a virtual environment
Windows
python -m venv venv
venv\Scripts\activate
Linux / macOS
python3 -m venv venv
source venv/bin/activate
Install dependencies
pip install -r requirements.txt
Apply database migrations
python manage.py migrate
Run the development server
python manage.py runserver

The application will be available at:

http://127.0.0.1:8000/
